忆言 · Windows 便携版使用说明
=========================================

一、这是什么
  一个图形界面的聊天程序：连接你自己的大模型接口，跟它对话、发图片、做屏幕识别、
  自动把聊天整理成记忆文件。已经打包成 exe —— 电脑上不需要安装 Python，双击即用。
  这是便携版：所有数据都放在 exe 所在文件夹里，不写系统用户目录，
  不会和这台电脑上已有的其它设置互相干扰。

二、怎么用（三步）
  1. 把压缩包解压到一个你有写入权限的目录，例如「桌面」、D:\忆言 或 U 盘。
     不要放在 C:\Program Files 这类需要管理员权限的目录（程序要往自己目录里写文件）。
  2. 解压出来是「忆言」和「源码」两个文件夹，进「忆言」文件夹，
     双击里面的 忆言.exe（首次启动要等 3~5 秒，属正常现象）。
  3. 第一次打开是设置页（输入框都是空的），至少要填「语言模型（LLM）接口信息」：
     接口地址 / API Key / 模型名称，也可以点「常见服务」标签一键填充，
     再点「测试语言模型连接」确认能通，然后点「保存并关闭设置」。

  设置页里还有几个可选大类（都是折叠的，需要时展开）：
   · 视觉模型（VLM）接口信息 —— 想发图片时用它识别图片内容
   · 屏幕识别 —— 定时截屏，自动当成你上传的图片
   · 记忆优化 —— 记忆文件太长时用指定模型精简
   · 对话总结 —— 记忆文件的份数 / 单份字数 / 每几轮生成一次

三、怎么发图片
  · 点输入框左上角的「＋ 图片」（可多选），或直接把图片拖进输入框；
  · 可以只发图片不写字，也可以图文一起发；
  · 发送后图片自动清空；图片会先交给视觉模型识别，再把识别结果和你的文字一起发给语言模型。

四、屏幕识别（可选）
  · 输入框上方有「📷 屏幕识别：开/关」按钮；在「设置 → 屏幕识别」里可以设：
    是否启用、每多少秒截一次、截取整个屏幕还是某个指定窗口、截图是否宽高减半。
  · 截取的图片会**自动放进待发送图片**里，你按发送才会真的发给模型（不会自动发送）。
  · 自动截图**始终只保留最新一张**（你手动挑的图片不受影响）。
  · 截图存在 exe 同目录的 temppicture 文件夹里，**最多保留 10 张**，超出先删最早的。
  · 想只盯某个软件，就在设置里点「选择窗口…」选中那个窗口。

五、记忆文件（对话总结）
  · 每聊满若干轮（默认 10 轮，可在设置里改），程序会让模型把这批对话整理成条目，
    写进 exe 同目录的 userdata\record\ 下，文件名就是生成时间（如 2026-10-14_21-41-09.md）。
  · 每条格式：序号. 内容 T(x),L(y),W(z)，末尾带「,D」表示这条被精简过。
    T = 该条距最新一条消息的天数 ÷ 所有条目里最大的天数（不足 1 天按 1 天计）；
    L = 该条字数 ÷ 所有条目里最大的字数；W = k·T + (1-k)·L（k 是设置里的时间权重）。
    条目按 W 从小到大排列**显示**，但**序号保持不变**（排序只改顺序、不改编号）；
    末尾带「,D」表示这条已被精简过。
  · **条目内容一旦生成就不再改动**：每次总结只追加新条目，并重算所有条目的 T/L/W；
    条目、时间与序号记在同名的 .items.json 里，关掉程序再打开也能接着累加。
  · 每聊满若干次（默认 10 次，可在设置里改），程序会自动把**目前累积的全部记忆条目**
    按**原序号从小到大**发给模型让它先回顾一遍，再回答你这次的问题 ——
    复习那一轮的聊天区会插一行浅色小字「📖 已让模型回顾以前的记忆（按原序号 …）」。
    注意：`userdata\record\` 里一份 .md 都没有时不会复习（状态栏会提示一行）。
  · 记忆文件太长（超过设置的字数或 2000 字）时，会调用「记忆优化」里配的模型，
    把 W 最大的、还没带 D 的若干条精简，直到字数达标；带 D 的条目过多时按规则删除。

六、文件都放在哪（都在 exe 同目录，便携）
  · 你的设置：llm_chat_config.json   ← 明文保存 API Key，别外发
  · 记忆文件：userdata\record\*.md   ← 以及同名的 *.items.json（条目、时间与序号）
  · 对话存档：userdata\ui_state.json ← 关掉程序再打开时用来接着聊（只有对话内容，不含 Key）
  · 屏幕截图：temppicture\*.png      ← 最多 10 张
  · 出错日志：llm_chat.log           ← 遇到问题把这个文件发给我即可
  注：软件这一版起改名叫「忆言」，但**内部文件名都没变**（llm_chat_config.json /
      .llm_gui_chat.json / llm_chat.log / userdata / temppicture），
      所以原来的设置与记忆文件照旧能用，改名不会丢东西。

七、关掉程序不会丢对话（对话存档）
  · 关掉再打开，**对话页面和 AI 的上下文都还在**，接着聊即可（轮次计数也接着算）。
  · 只有你手动点对话页右上角的**「清空对话」**才会清除（会同时删掉 ui_state.json）；
    聊天区回到欢迎页 = 已经清空。

八、常见问题
  · 双击没反应或被拦截：这是自制未签名程序，Windows 可能提示风险，点「更多信息」→「仍要运行」；
    杀毒软件误报时请加白名单（PyInstaller 打包程序常见误报，属正常）。
  · 提示 404：接口地址多半少了 /v1；提示 401：API Key 不对或没填。
  · 提示无法写入：把整个文件夹换个有写入权限的位置（别放 Program Files）。
  · 想确认程序功能是否完好：在 exe 所在目录打开命令行执行
        忆言.exe --selftest
    会在同目录生成 selftest-report.txt，里面全是 ✅ 说明一切正常。

九、包里有什么
  解压后是两个并列的文件夹：

  忆言\               可以直接运行的程序
    忆言.exe          主程序（免安装、便携，直接运行）
    test.jpeg         示例图片，用于测试视觉模型能不能识别图片
    使用说明.txt      本文件
    README.md         完整功能说明（每个功能细节、常见问题、参考出处）

  源码\               项目完整源码（和 exe 是同一份代码，可自行改后重新打包）
    llm_chat.py       主程序源码（纯 Python 标准库实现，零第三方依赖）
    start.bat         双击即可用源码运行（需要本机装 Python 3.8+）
    README.md         完整功能说明
    test.jpeg         示例图片
    .gitignore        不会提交的个人数据/密钥/构建产物清单
    packaging\        图标、打包脚本、version.txt、忆言.spec、使用说明.txt
    源码说明.txt      这一份源码的来源提交 / 怎么运行 / 怎么重新打包
